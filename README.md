# Mini Project 3 + 4 — TV Show Search

A simple TV Show Search application using the TVmaze API.

## Features
- Search TV shows using the TVmaze API
- Fetch API data with `fetch()` and `async/await`
- Dynamically render show cards using DOM methods
- Show loading, error, and empty-result messages
- Add and remove favourite shows
- Save favourites in Local Storage so they remain after refresh

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Search for a TV show by name.

## API
This project uses the public TVmaze search endpoint:
`https://api.tvmaze.com/search/shows?q=QUERY`

## Technologies
HTML, CSS, JavaScript, Fetch API, DOM, Local Storage.

## Mini Project 3 + 4
This project demonstrates dynamic DOM rendering, event handling, JavaScript array methods, asynchronous API integration, and Local Storage persistence.
